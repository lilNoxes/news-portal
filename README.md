# 📰 ИнфоЛента — Новостной портал с авто-обновлением

Современный и быстрый агрегатор новостей в реальном времени. Автоматически собирает свежие материалы из проверенных RSS-лент, сохраняет в локальную базу данных SQLite, исключает дубликаты и регулярно обновляет контент в фоновом режиме.

---

## ✨ Возможности

- **Автоматический сбор и обновление**: Встроенный фоновый планировщик (`node-cron`) опрашивает источники каждые 10 минут.
- **Мгновенное ручное обновление**: Кнопка «Обновить» на панели управления для принудительного сбора свежих новостей.
- **Интеллектуальная суммаризация (Gemini AI TL;DR)**: Мгновенное извлечение сути новости в 3 тезиса с помощью Google Gemini Flash (`@google/genai`) и умным кэшированием в SQLite.
- **Сводный Дайджест Дня (Gemini AI)**: Генерация единой картины дня и трендов за последние 24 часа по клику на кнопку «AI Дайджест».
- **Полнотекстовый поиск SQLite FTS5**: Высокоскоростной морфологический поиск по всей базе статей с токенизатором `unicode61`.
- **Работает без платных API-ключей**: Используются открытые полноформатные RSS-ленты без ограничений на количество запросов.
- **Надежное хранение в SQLite**: Дедупликация статей по ссылке/GUID, автоматическая ротация устаревших материалов (14 дней).
- **Категории и рубрики**: *Главное*, *Технологии*, *Бизнес*, *Наука* с подсчетом количества публикаций.
- **Закладки (Избранное)**: Сохранение интересных новостей в браузере в один клик.
- **Защищенная панель администратора**: Вход по паролю с защитой от брутфорса (`express-rate-limit`), SSRF-фильтрацией и управлением источниками RSS.
- **Темная и светлая тема**: Автоматическое определение предпочтений системы + ручной переключатель с сохранением настроек.
- **Модальный режим чтения**: Просмотр анонса и текста новости прямо на сайте с кнопкой перехода к оригиналу.

---

## 🛠 Технологический стек

- **Бэкенд**: Node.js, Express, `@google/genai` (Gemini SDK 2.3+), `better-sqlite3` (SQLite WAL + FTS5), `compression` (Gzip/Brotli), `rss-parser`, `sanitize-html`, `express-rate-limit`, `node-cron`, `cheerio`, `cors`.
- **Фронтенд**: React 18, Vite, Tailwind CSS, `dompurify` (защита от XSS), Lucide React (иконки).
- **База данных**: SQLite (файл `server/news.db`, режим WAL, FTS5 полнотекстовый индекс).

## 🚀 Быстрый запуск

### 1. Установка всех зависимостей
```bash
npm run install:all
```
*(установит пакеты для корневой папки, бэкенда и фронтенда)*

### 2. Запуск проекта в режиме разработки
```bash
npm run dev
```
Команда одновременно запустит:
- **Бэкенд API**: `http://localhost:3001`
- **Веб-интерфейс**: `http://localhost:5173`

### 3. Переменные окружения (.env)
Создайте файл `.env` в папке `server/` (или корне):
```env
PORT=3001
ADMIN_PASSWORD=your_secure_password
AUTH_SECRET=your_random_secret_token
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash
```
> *Примечание:* Если `GEMINI_API_KEY` не указан, портал работает в штатном режиме, а при нажатии на AI-функции подсказывает добавить ключ.

## 📁 Структура проекта

```text
├── package.json          # Корневые скрипты запуска (dev, build, install:all)
├── server/
│   ├── index.js          # Express API сервер, rate limiting, auth и cron
│   ├── db.js             # Инициализация SQLite, foreign keys и ротация TTL
│   ├── newsFetcher.js    # Модуль парсинга RSS, санитизации HTML и мьютекс
│   ├── news.db           # База данных SQLite (создается автоматически)
│   └── package.json
└── client/
    ├── index.html
    ├── vite.config.js    # Проксирование /api на localhost:3001
    ├── tailwind.config.js
    └── src/
        ├── App.jsx
        ├── components/
        │   ├── Header.jsx             # Шапка с поиском, датой, темой и кнопками

        │   ├── NewsCard.jsx           # Карточка новости с превью и закладками
```
