# 📰 ИнфоЛента — Новостной портал с авто-обновлением

Современный и быстрый агрегатор новостей в реальном времени. Автоматически собирает свежие материалы из проверенных RSS-лент, сохраняет в локальную базу данных SQLite, исключает дубликаты и регулярно обновляет контент в фоновом режиме.

---

## ✨ Возможности

- **Автоматический сбор и обновление**: Встроенный фоновый планировщик (`node-cron`) опрашивает источники каждые 10 минут.
- **Мгновенное ручное обновление**: Кнопка «Обновить» на панели управления для принудительного сбора свежих новостей.
- **Работает без платных API-ключей**: Используются открытые полноформатные RSS-ленты без ограничений на количество запросов.
- **Надежное хранение в SQLite**: Дедупликация статей по ссылке/GUID, молниеносные выборки с индексами.
- **Категории и рубрики**: *Главное*, *Технологии*, *Бизнес*, *Наука* с подсчетом количества публикаций.
- **Быстрый поиск**: Поиск по заголовкам и описанию статей с дебаунсом при вводе.
- **Закладки (Избранное)**: Сохранение интересных новостей в браузере в один клик.
- **Управление источниками (RSS)**: Модальное окно для включения/выключения каналов и добавления собственных RSS-лент.
- **Темная и светлая тема**: Автоматическое определение предпочтений системы + ручной переключатель с сохранением настроек.
- **Модальный режим чтения**: Просмотр анонса и текста новости прямо на сайте с кнопкой перехода к оригиналу.

---

## 🛠 Технологический стек

- **Бэкенд**: Node.js, Express, `rss-parser`, `better-sqlite3`, `node-cron`, `cheerio`, `cors`.
- **Фронтенд**: React 18, Vite, Tailwind CSS, Lucide React (иконки).
- **База данных**: SQLite (файл `server/news.db`, режим WAL).

---

## 🚀 Быстрый запуск

### 1. Установка всех зависимостей
```bash
npm run install:all
```
*(установит пакеты для корневой папки, бэкенда и фронтенда)*

### 2. Запуск проекта в режиме разработки
```bash
npm run dev
```
Команда одновременно запустит:
- **Бэкенд API**: `http://localhost:3001`
- **Веб-интерфейс**: `http://localhost:5173`

При первом запуске сервер автоматически загрузит свежие новости из всех настроенных источников.

## 📁 Структура проекта

```text
├── package.json          # Корневые скрипты запуска (dev, build, install:all)
├── server/
│   ├── index.js          # Express API сервер и планировщик cron
│   ├── db.js             # Инициализация базы SQLite и начальные источники
│   ├── newsFetcher.js    # Модуль парсинга RSS, очистки текста и сохранения
│   ├── news.db           # База данных SQLite (создается автоматически)
│   └── package.json
└── client/
    ├── index.html
    ├── vite.config.js    # Проксирование /api на localhost:3001
    ├── tailwind.config.js
    └── src/
        ├── App.jsx
        ├── components/
        │   ├── Header.jsx         # Шапка с поиском, датой, темой и кнопками
        │   ├── CategoryFilter.jsx # Рубрики и фильтры с бейджами
        │   ├── NewsCard.jsx       # Карточка новости с превью, временем и закладками
        │   ├── NewsModal.jsx      # Модальное окно чтения новости
        │   ├── SourcesModal.jsx   # Управление RSS-источниками
        │   └── StatsBanner.jsx    # Информационный баннер статистики
        └── utils/
            └── dateUtils.js       # Форматирование времени на русском языке
```
